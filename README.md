# FileHop

FileHop — настольное приложение для передачи файлов между компьютерами и телефоном в одной локальной сети. Оно поднимает небольшой HTTP-сервер на порту 7431 и показывает QR-код или ссылку для подключения.

## Возможности

- Получение файла с телефона через веб-страницу по QR-коду и коду доступа.
- Передача файла на телефон по ссылке из QR-кода.
- Обнаружение других компьютеров с FileHop в локальной сети и отправка файла напрямую.
- Светлая, тёмная и системная темы.
- Прогресс передачи для отправки файла на другой ПК и на мобильной странице.

## Требования

- Node.js и npm.
- Rust и Cargo (через инструменты Tauri v2).
- Windows, macOS или Linux с установленными зависимостями Tauri для вашей платформы.

Если `node`, `rust` или `git` отсутствуют, приложение не запустить без их установки; в рамках этого репозитория они не устанавливаются автоматически.

## Разработка

```bash
npm install
npm run tauri dev
```

Проверки без запуска приложения:

```bash
cargo check --manifest-path src-tauri/Cargo.toml
npm run check
```

Сборка релиза:

```bash
npm run tauri build
```

## Как пользоваться

1. Запустите FileHop на компьютере.
2. Откройте вкладку «QR-код».
3. Для получения с телефона отсканируйте QR-код, введите на телефоне шестизначный код с компьютера и отправьте файл.
4. Для отправки на телефон выберите файл, отсканируйте QR-код или скопируйте ссылку под ним. Ссылка действует 10 минут.
5. Для передачи между компьютерами откройте вкладку «Устройства», дождитесь появления нужного ПК и нажмите «Отправить файл».

Настройки темы и ручного IP-адреса сохраняются автоматически. Ручной IP нужен, если автоопределение выбирает сетевой интерфейс VPN или виртуальной машины.

## Модель доверия и безопасность

- FileHop предназначен для доверенной локальной сети. HTTP-сервер слушает `0.0.0.0:7431`, чтобы телефон и другие компьютеры могли подключиться.
- `/upload` (загрузка с телефона) требует шестизначный код доступа. Неудачные попытки ограничены: не более 5 в минуту с одного IP.
- `/upload_pc` (передача между компьютерами) намеренно не требует код доступа, чтобы сохранить рабочий сценарий ПК-ПК. Не добавляйте проверку кода без изменения протокола обнаружения и отправки.
- Ссылка на скачивание содержит случайный токен и действует 10 минут; просроченные файлы удаляются.
- Tauri capabilities ограничены повседневными действиями: доступ к диалогам открытия/сохранения и базовые разрешения окна.
- CORS в текущей версии разрешает любые origin. Это сделано намеренно: десктопный UI обращается к локальному серверу из webview. Сужать список origin без проверки вкладок и статуса не рекомендуется.

## Ограничения

- Максимальный размер загружаемого файла — 4 ГиБ. Данные записываются на диск потоково, без полной загрузки в память.
- Время жизни ссылки на скачивание — 10 минут.
- UDP-обнаружение устройств работает через широковещательные пакеты на портах 7432 и 7433; некоторые сети могут блокировать broadcast.
- Мобильная страница показывает предупреждение о размере файла, но не блокирует отправку.

## Структура проекта

- `src/` — интерфейс SvelteKit.
- `src-tauri/src/lib.rs` — Tauri-команды, UDP-обнаружение и запуск сервера.
- `src-tauri/src/server/` — HTTP-сервер, обработчики и состояние.
- `src-tauri/capabilities/` — разрешения Tauri.
